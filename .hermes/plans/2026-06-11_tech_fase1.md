# Rencana Implementasi: Fase 1 (Profil & Pengaturan) APK Teknisi

> **Untuk Hermes:** Gunakan skill `subagent-driven-development` jika mendelegasikan, atau eksekusi langkah demi langkah dengan `todo` tool.

**Goal:** Menggantikan halaman stub Profil dan Pengaturan di aplikasi Teknisi (`mobile-technician`) dengan fitur fungsional penuh (Edit Profil, Ganti Password, dan Pengaturan Biometrik/Notifikasi/Bahasa) setara dengan Customer App.

**Architecture:** Memanfaatkan Riverpod `authControllerProvider` untuk interaksi API dengan class `AuthService` dan local storage. Menggunakan custom widget dari package `ui_kit` untuk menyamakan design system (dark/light mode dan responsive layout).

**Tech Stack:** Flutter, Riverpod, GoRouter, flutter_secure_storage, local_auth.
